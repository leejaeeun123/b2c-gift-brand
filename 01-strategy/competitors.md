# 경쟁 지형 & 포지셔닝 맵

> 2026-08-23 · 기준: **3~7만 원 선물을 고르는 사람이 실제로 여는 창**

---

## 1. 진짜 경쟁자는 편집숍이 아니다

3~7만 원 선물이 필요한 사람이 가장 먼저 여는 건 **카카오톡 선물하기**다. 여기를 인정하지 않으면 경쟁 분석이 공허해진다.

| 경쟁 | 어떤 손님을 가져가나 | 그쪽의 강함 | 그쪽이 못 하는 것 |
|---|---|---|---|
| **카카오 선물하기** | 주소를 모르는 사이, 급한 사람 | 주소 불필요, 즉시 전송, 교환 가능 | **포장이 없다.** 브랜드 상품 위주라 '고른 티'가 안 난다. 테이블웨어 취약 |
| **네이버 스마트스토어 '집들이 선물세트'** | 가격만 보는 사람 | 최저가, 검색 상단 | 조악한 포장, 브랜드 없음, 사진이 다 똑같음 |
| **로파서울 · inapsquare** | 안목을 증명하려는 사람 | 큐레이션 신뢰, 작가 상품 | 단가 높음(단품 5~40만), 캐주얼 선물엔 무겁고 톤이 차갑다 |
| **텐바이텐 · 1300K** | 실용 선물 찾는 사람 | 넓은 SKU, 선물 UI 성숙 | 백화점화되어 취향이 안 읽힘 |
| **오늘의집 스토어** | 인테리어 맥락 | 트래픽, 스타일링컷 | 선물 문법이 아니라 자가소비 문법 |
| **이케아 · 대형 리빙 브랜드** | 저가 실속 | 가격, 접근성 | 선물로 주기엔 '아무나 사는 것' |

### 여기서 나오는 두 가지 결론

1. **카카오가 못 하는 건 '고른 티'뿐이다.** 무주소 배송·메시지카드·가격 노출 제거는 **카카오와 29CM가 이미 한다.**
   즉 선물 완결 프로세스는 차별점이 아니라 **기준선**이다. 안 하면 지지만, 해도 이기지 못한다.
   남는 건 하나 — **무엇을 왜 골랐는지.** 플랫폼은 셀렉션에 관점을 못 싣는다(입점사가 보고 있다). 우리는 실을 수 있다.
2. **동시에 카카오를 흉내는 내야 한다** — 주소를 몰라 못 보내는 경우가 실제로 많다. 자사몰에 **배송지 대신 링크로 보내기**(받는 사람이 주소 입력)를 넣으면 이탈이 크게 준다. Phase 5 기능 요구사항으로 넘긴다.

## 2. 포지셔닝 맵

```
                     선물로 완성돼서 온다
                              ▲
                              │
              (우리)  ●───────┼
             그림 포장 · 세트  │
             3~7만원          │        ● 로파서울
                              │          단품 오브제 · 안목 증명
       친근·손그림 ◄──────────┼──────────► 절제·갤러리
                              │        ● inapsquare
     ● 스마트스토어 선물세트   │
       싸지만 성의 안 보임     │        ● 오늘의집 / 이케아
                              │          자가소비 문법
                              ▼
                       그냥 상품이 온다
```

**좌상단이 비어 있다.** 친근한 톤 + 선물 완결도. 이유는 단순하다 — 친근한 톤으로 가는 곳은 대개 저가로 가고, 선물을 완성해서 보내는 곳은 대개 비싸고 차갑다. 이 둘을 같이 하는 건 운영이 귀찮아서지 어려워서가 아니다.

> 다만 **귀찮음만으로는 해자가 안 된다.** 카카오·29CM가 이미 그 귀찮은 일을 하고 있기 때문이다.
> 좌상단 자리를 지키는 건 프로세스가 아니라 **셀렉션에 실린 관점**이다(→ [`PLAN.md` §3.1](../PLAN.md)).

## 3. 가격대 실측 비교

| | 주력 단가 | 무엇이 오나 |
|---|---|---|
| 스마트스토어 세트 | 20,000~40,000 | 상품 + 비닐 뽁뽁이 |
| **우리** | **30,000~70,000** | **세트 + 그림 포장 + 카드** |
| 로파서울 GIFT '가벼운 선물' | 45,000~85,000 | 단품 1점 + 기본 포장 |
| 로파서울 '깊이 있는 선물' | 250,000~600,000 | 작가 오브제 |

우리는 스마트스토어보다 1.5배 비싸고 로파서울보다 싸다. **그 차액을 무엇으로 설명할 것인가**가 상세페이지의 유일한 임무다. 답: 세트 구성 + 포장 + 카드 + 안 겹칠 확률.
