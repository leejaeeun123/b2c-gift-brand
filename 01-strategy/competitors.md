## 1. 직접 경쟁 — 테이블웨어 편집숍/브랜드 지형

### 1-1. 한눈에

| 구분 | 대표 | 상품 출처 | 가격대(식기) | 1차 카테고리 | 그림/캐릭터 | 선물 문법 |
|---|---|---|---|---|---|---|
| **작가 갤러리형** | 요소갤러리 · 쿠도(CUDO) | 국내 도자 작가 | 2만~30만(주력 3~8만) | **작가(Artists)** | 없음 | Gift 카테고리 보유, 세트 판매 |
| **수입 편집형** | 서울번드 | 해외 브랜드 수입 | 중~고가 | 브랜드 | 없음 | 약함 |
| **자체 브랜드형(무장식)** | 화소반 | **자체 제조** | 중가 | 색·용도 | **의도적으로 없음** | 중간 |
| **자체 브랜드형(일러스트)** | **여기담기** | **자체 제조** | 중가 | 그림 시리즈 | **핵심 자산** | 중간 |
| **큐레이션 상위** | 로파서울 · inapsquare | 작가·수입 | 4.5만~60만 | **GIFT 최상위 + 상황·무게 2중** | 없음(절제) | **최강** |
| **가격 경쟁** | 스마트스토어 '집들이 선물세트' | 도매 | 2만~4만 | 검색어 | 없음 | 비닐 뽁뽁이 |
| **레거시 대형** | 한국도자기 · 웨지우드 | 자체 제조 | 넓음 | 라인 | 없음 | 강함(선물 관습) |

### 1-2. 개별 판단

**요소갤러리 — 지금 가장 가까운 상단 경쟁자**
`Artists / Set / Dining / Cafe&Bar / Cutlery / Deco / **Gift** / Last One Sale` 8개 카테고리로 진열합니다.
주력 3~8만 원대로 **우리 가격대와 정면으로 겹치고**, Gift와 Set을 이미 갖췄습니다.
- 그쪽의 강함: **작가 이름**이 상품의 근거. 우리가 지금 못 가진 것(→ 그래서 B(작가·공방) 카테고리을 보류했었다)
- 그쪽의 빈틈: 1차 카테고리이 **작가**라서, "집들이 선물 뭐 사지"로 들어온 사람이 길을 잃습니다.
  상황에서 출발하는 동선이 없습니다. **우리 A(상황) 카테고리이 노리는 자리가 정확히 여기입니다.**
- 톤: 갤러리. 따뜻함보다 정제. 손그림 톤과 겹치지 않습니다.

**쿠도(CUDO)** — 국내 작가 도자기 셀렉트샵. 요소갤러리와 같은 층, 규모가 작습니다.
1차 카테고리가 품목(도자기그릇/핸드메이드작가그릇/디자인그릇)이라 선물 문법이 약합니다.

**여기담기 — 컨셉이 가장 가까운, 그래서 가장 조심할 상대**
위트 있는 일러스트를 그려 넣은 그릇을 **직접 만듭니다.** 우리가 PLAN §3.1에서 3단계(6개월~)로
잡아 둔 자리를 **이미 점유하고 있는 브랜드**입니다.
- 그쪽의 강함: 그림이 **상품 표면에 있다.** 우리 1단계는 그림이 포장에만 있습니다. 그림의 진정성이 다릅니다
- 그쪽의 빈틈: **브랜드지 편집숍이 아닙니다.** 자기 그림을 얹은 자기 라인만 팝니다.
  "집들이 선물 한 상"을 구성해 주지는 못합니다. 선물 완결 서비스도 약합니다
- **우리의 분기점**: 우리는 단품 그릇으로 싸우지 않습니다. **상황 × 조합 × 포장**으로 나뉩니다.
  단품 경쟁으로 끌려가는 순간 우리가 집니다 — 제조를 안 하니까요

**화소반 — 반대편의 좋은 대조군**
"그림을 그리거나 장식을 하지 않는다"를 원칙으로 색만으로 승부합니다. 우리와 정확히 반대입니다.
이 브랜드의 존재가 증명하는 것: **테이블웨어에서 '장식 없음'은 이미 점유된 자리**라는 것.
우리가 손그림으로 가는 판단을 뒷받침합니다.

**로파서울 · inapsquare** — 구조의 스승이고 가격의 다른 층. 해부는 [`reference-lofa.md`](./reference-lofa.md).
경쟁이라기보다 **우리가 가려는 구조의 완성형**입니다. 겹치는 손님은 적습니다(5만 원 단품 vs 5만 원 세트).

**스마트스토어 선물세트** — 검색 상단을 가져갑니다. 이길 필요가 없고, **Tier 0에서 우리도 그 매대에 섭니다.**
같은 매대에서 "포장이 다른 쪽"으로 서면 됩니다.

## 2. 그래서 우리가 실제로 비어 있다고 주장할 수 있는 자리

교차해서 비어 있는 칸은 하나입니다.

```
                    상황(선물)에서 출발한다
                              ▲
                              │
            ●(우리)  ─────────┼           ● 로파서울
      상황 + 세트 + 손그림   │             상황 O · 단품 · 절제 · 고가
      3~7만 · 자체 기획 세트   │
                              │
   그림·캐릭터 ◄──────────────┼──────────────► 무장식·절제
   ● 여기담기                 │           ● 요소갤러리 · 쿠도 · 화소반
     그림 O · 자체 제조        │             작가/색 기준 · 선물 동선 없음
     선물 동선 없음            │
                              ▼
                     상품(카테고리·작가)에서 출발한다
```

**좌상단이 비어 있습니다.** 손그림·캐릭터 톤 + 상황 진열 + 세트 + 3~7만 원.
- 그림을 가진 곳(여기담기)은 **제조사라 편집·조합을 안 합니다.**
- 상황 카테고리을 가진 곳(로파서울)은 **톤이 절제되고 값이 배입니다.**
- 편집을 하는 곳(요소갤러리·쿠도)은 **작가 카테고리이라 선물 동선이 없습니다.**

셋 다 하는 곳이 없는 이유는 어렵기 때문이 아니라, **각자 자기 강점의 반대편이기 때문**입니다.
제조사는 남의 물건을 안 팔고, 갤러리는 귀여워지지 않습니다.

## 3. 가격대 실측

| | 주력 단가 | 무엇이 오나 |
|---|---|---|
| 스마트스토어 세트 | 20,000~40,000 | 상품 + 비닐 뽁뽁이 |
| 여기담기(단품 중심) | 중가 단품 | 그림 그려진 그릇 1점 |
| **우리** | **30,000~70,000** | **기획 세트 + 그림 포장 + 카드 + 고른 이유** |
| 요소갤러리 주력 | 30,000~80,000 | 작가 단품 또는 세트 |
| 로파서울 '가벼운 선물' | 45,000~85,000 | 단품 1점 + 기본 포장 |
| 로파서울 '깊이 있는 선물' | 250,000~600,000 | 작가 오브제 |

**요소갤러리와 우리는 같은 가격표를 씁니다.** 차액을 설명하는 게 아니라 **같은 값에 다른 것**을 줘야 합니다.
그쪽은 작가 이름을, 우리는 **구성과 포장과 이유**를 줍니다.

## 4. 대체 선택지 — 진짜로 자주 지는 상대

| 대체재 | 왜 선택되나 | 우리가 이기는 조건 |
|---|---|---|
| **상품권·현금** | 안 겹친다. 실패가 없다 | "겹치지 않게 골랐다"를 **증명**해야 한다. 이것이 §2의 조합 카피가 존재하는 이유 |
| 꽃·케이크 | 부담 없고 예쁘다 | 남는 물건. "오래 곁에 둔다"(거북이 축) |
| 커피 기프티콘 | 싸고 빠르다 | 가격대가 다르다. 경쟁 아님 |
| 가전 소형 | 실용 | 5만 원대에선 초라해진다 |

**상품권이 진짜 경쟁자입니다.** 편집숍이 아니라. 그릇 선물의 최대 리스크는 '겹침'이고,
상품권은 그 리스크가 0입니다. 우리 상세페이지의 임무는 여기서 나옵니다 —
**겹칠 확률을 낮추는 판단을 보여 주는 것.**
