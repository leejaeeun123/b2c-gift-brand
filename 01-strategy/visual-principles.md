# 비주얼 원칙

> 무드 키워드는 **3개**. 이 셋으로 설명 안 되는 결정은 하지 않는다.

---

## 무드 키워드

| 키워드 | 뜻 | 어디서 보이나 |
|---|---|---|
| **손의 흔적** | 자로 잰 선이 아니라 사람이 그은 선. 굵기가 일정하지 않고, 끝이 조금 삐뚤다 | 로고 · 일러스트 · 아이콘 · 카드 |
| **담백한 밝음** | 밝지만 달지 않다. 채도는 있고 탁하지 않다. 종이 흰색이 바탕 | 컬러 · 촬영 · 배경 |
| **넉넉한 여백** | 꽉 채우지 않는다. 그림이 놓일 자리를 남긴다 | 레이아웃 · 패키지 · 상세페이지 |

세 키워드가 함께 만드는 인상: **누가 손으로 그려서 싸 준 것 같은데, 지저분하지는 않은.**

---

## 원칙

### 1. 그림과 사진은 자리를 나눈다
손그림은 **여백·패키지·카드·에디토리얼**에 산다. **제품 사진 위에 일러스트를 얹지 않는다.**
도자기는 색과 질감이 상품이다. 그 위에 선을 그으면 상품이 안 보이고 아마추어처럼 읽힌다.

### 2. 그림은 한 손이어야 한다
로고 하나 그리고 끝나는 게 아니다. **선 굵기 · 모서리 처리 · 채색 방식 · 그리지 않는 것**을 규칙으로 정해서,
누가 그려도 같은 손으로 보이게 만든다. → Phase 3 `illustration-system.md`, 모티프 사전 **≥12종**이 완료 조건.

### 3. 여백이 곧 가격대다
3~7만 원에서 고급스러움은 재료가 아니라 여백에서 온다. 요소를 더 넣고 싶을 때가 위험 신호다.

### 4. 상황이 색보다 먼저 보인다
진열·배너·썸네일에서 가장 먼저 읽혀야 하는 건 상품명도 브랜드명도 아니라 **상황 라벨**이다.

### 5. 작게 줄여도 살아야 한다
손그림 로고의 최대 리스크다. 파비콘·택·스티커·자수·도자기 각인까지 **최소 사이즈 테스트가 Phase 3 완료 조건.**
줄였을 때 뭉개지면 선을 단순화한다 — 귀여움보다 생존이 먼저다.

## 회피 방향 — 무엇을 안 하는가

> 이 절이 이 문서에서 가장 중요하다. 손그림+여성 타겟은 **가만두면 전부 같은 곳으로 수렴한다.**

| 회피 | 왜 |
|---|---|
| **파스텔톤** *(사용자 확정)* | 여성 타겟 손그림이 가장 쉽게 빠지는 함정. 유아용품·문구점으로 읽히고 3~7만 원 가격이 설명되지 않는다 |
| **기계적 대칭 · 그라디언트 · 균일한 벡터 선** | "AI가 그린 귀여움"으로 읽히는 순간 브랜드의 얼굴이 사라진다. 그림은 안목을 보이게 하는 장치인데, 장치가 흔해 보이면 안목도 흔해 보인다 |
| 크래프트지 + 마끈 + 스탬프 | 핸드메이드 클리셰. 우리는 만든 척하지 않는다(→ 보이스 3번) |
| 캘리그라피 감성 문구 | "오늘도 수고했어" 류. 우리 보이스(구체적·솔직한)와 정면 충돌 |
| 캐릭터를 **로고 자리에** 세우기 | 캐릭터가 상품을 이기면 그릇이 안 팔린다. 로고는 워드마크 단독이다. *(2026-08-23 수정 — 캐릭터 자체는 채택. 거북이 1종, 규칙은 [`03-identity/character.md`](../03-identity/character.md))* |
| 제품 사진 위 일러스트 · 스티커 남발 | 원칙 1 위반 |
| 갤러리식 무채색 절제 | 로파서울·inapsquare의 자리다. 따라가면 열화판이 된다 |
| 시즌 컬러 총동원(레드그린·핑크하트) | 상황 축은 사시사철 도는 게 강점 |

## 컬러

파스텔을 뺀 자리를 무채색으로 메우면 갤러리 톤이 되어 또 다른 회피 방향에 걸린다. 그래서 잠정 방향은:

**확정(2026-08-23) — 2색.** 종이 `#FFFFFF` · 잉크 `#262320`. **포인트 컬러 없음.**
위계는 잉크의 농도로, 강조는 면 반전과 굵기로 만든다. 회색이 필요하면 새 색을 만들지 않는다.

> 앞서 "무채색으로 메우면 갤러리 톤"이라 우려했으나, 이 팔레트는 무채색이 아니고(아이보리+먹빛)
> 무엇보다 **손그림이 따뜻함을 담당한다.** 색까지 따뜻하려 들면 이중과세다.
> 정본은 [`03-identity/color-palette.md`](../03-identity/color-palette.md).

## 촬영 방향 `[추정]`

| | |
|---|---|
| 비율 | 스타일링컷 : 제품컷 = **6 : 4**. inapsquare(장면 위주)와 스마트스토어(누끼 위주)의 중간 |
| 필수컷 | ① 세트 전체 ② 크기 비교(손 또는 밥공기와 함께) ③ **포장 상태** ④ 뜯는 장면 |
| 배경 | 종이 아이보리 / 원목 / 리넨. 대리석·유광 아크릴 제외(차갑다) |
| 조명 | 자연광. 그림자를 지우지 않는다 — 여백에 그림자가 있어야 종이처럼 보인다 |
| 금지 | 과채도 보정 · 뽀샤시 필터 · 상품 위 텍스트 떡칠 |

③ **포장 상태 컷은 필수다.** 우리 차별점이 거기 있는데 사진이 없으면 존재하지 않는 것과 같다.
