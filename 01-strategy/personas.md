# 페르소나

> 3인. 선물 편집숍의 손님은 **구매자와 사용자가 다르다** — 이 분리가 모든 설계의 출발점이다.
> 페르소나는 인구통계가 아니라 **실패 공포**로 정의한다. 선물은 실패하기 싫어서 사는 물건이다.

---

## P1. 집들이 가는 사람 — **주력**

| | |
|---|---|
| 누구 | 30대 초반 직장인 여성. 친구가 신혼집 또는 첫 자취방에 초대 |
| 예산 | **5만 원 안팎** (3만은 성의 없어 보이고, 10만은 부담을 준다) |
| 시점 | 집들이 3~5일 전. 급하지는 않지만 미루다 온 상태 |
| 검색어 | "집들이 선물", "집들이 선물 5만원", "집들이 선물 안 겹치는" |

**실패 공포 (중요도 순)**
1. **겹치는 것** — 다른 사람도 사 온 그것. 집들이 선물의 1번 공포다.
2. **이미 있는 것** — 신혼집엔 밥그릇이 이미 있다.
3. **취향 없어 보이는 것** — 고른 사람이 평가받는다.
4. 부담 주는 것 — 너무 비싸면 상대가 불편해한다.

**우리가 줄 답**: 세트 구성으로 "겹칠 확률"을 낮추고(단품보다 조합이 겹치기 어렵다), 포장으로 "고른 티"를 만든다. 상세페이지에 *이미 있어도 안 아까운 이유*를 쓴다.

> P1은 우리 매출의 축이자, **상황 라벨 '집들이·이사'가 첫 번째로 오는 이유**다.

## P2. 고마움 갚는 사람

| | |
|---|---|
| 누구 | 20대 후반~30대 여성. 신세 진 선배·친구·이웃·강사 |
| 예산 | **3만 원대** — 금액이 커지면 오히려 상대가 부담을 느낀다 |
| 시점 | 고마운 일이 있고 나서 1~2주 안. 타이밍이 지나면 어색해진다 |
| 검색어 | "감사 선물", "부담 없는 선물", "3만원 선물" |

**실패 공포**
1. **부담 주는 것** — 갚아야 할 빚처럼 느껴지면 실패다.
2. 사무적으로 보이는 것 — 기프티콘은 성의가 안 보인다.
3. 사적으로 과한 것 — 관계 대비 너무 개인적인 물건은 부담이다.

**우리가 줄 답**: **카드**다. 3만 원대에서 성의를 만드는 건 물건이 아니라 말이다. 우리 그림 카드에 짧은 손글씨가 들어가면 3만 원이 5만 원처럼 도착한다. → 그림 자산이 가장 크게 일하는 페르소나.

---

## P3. 나에게 주는 사람 — **숨은 매출**

| | |
|---|---|
| 누구 | 20대 후반~30대 여성. 혼자 살거나 둘이 산다 |
| 예산 | 3~7만 원. 다만 **구매 빈도가 가장 높다** |
| 시점 | 선물 사러 왔다가 자기 것을 담는다. 또는 이사·계절 바뀜·기분 전환 |
| 검색어 | "예쁜 접시", "2인 식기세트", "혼자 밥 예쁘게" |

**실패 공포**
1. **못 쓰게 되는 것** — 전자레인지 안 되고 손설거지만 되면 결국 안 쓴다.
2. 사진과 다른 것 — 색·크기가 다르면 반품이 귀찮아 그냥 안 쓴다.
3. 다른 그릇과 안 어울리는 것.

**우리가 줄 답**: **스펙 정직함.** 전자레인지·식기세척기·오븐 가능 여부를 아이콘으로 명시하고, 실제 크기를 손·밥그릇과 함께 찍는다. 로파서울 상세페이지가 못 하는 것이 여기다(→ [`reference-lofa.md` §6](./reference-lofa.md)).

> P3는 선물가게에서 계산이 잘 안 잡히는 축이지만, **재구매의 대부분을 만든다.** 선물은 1년에 몇 번이고 자기 것은 계속 산다. 다만 브랜드 얼굴은 P1·P2로 만든다 — 얼굴을 P3로 잡으면 그냥 그릇가게가 된다.

## 제외한 후보

| 후보 | 제외 사유 |
|---|---|
| **취업 / 입학 선물** | 3~7만 원 캐주얼 테이블웨어와 어긋난다. 이 예산의 취업 선물은 지갑·향수·명함집으로 가고, 테이블웨어는 "자취 시작"일 때만 걸린다 — 그건 P1의 이사 라벨로 흡수된다. *(2026-08-23 확정)* |
| 명절·시가 선물 | 예산대와 톤(격식)이 완전히 다르다. 브랜드가 무거워진다 |
| 기업 단체 선물(B2B) | 레포명이 b2c다. 나중에 물량이 붙으면 별도 라인으로 |
| 돌잔치·출산 | 유아 안전 규격 이슈. 초기엔 감당 안 된다 |
