## 2. 소로이샵 상세 — 실제 순서

```
① 히어로: 박스 뚜껑 연 컷(크라프트 박스 + 흰 습자지 + 접시 4장)
② 제목 "파스텔 블루 앞접시 4P 선물세트" + 소개 6줄(품목마다 수식어 1개씩: 사랑스러운·고급스러운·은은한·고풍스러운)
③ 용도 한 단락(포인트 사용·집들이 손님맞이)
④ 포장 고지: "선물용 박스 포장이 포함… 시즌에 따라 박스 디자인·스티커·엽서 구성 변경 가능. 쇼핑백 미포함"
⑤ 제품구성 한 줄 (품목 + 사이즈 + 1P 나열)
⑥ 품목별 단독컷 4장 + 이름 + 지름·밑지름·높이·무게(약 165g)
⑦ 4장 톱뷰 집합컷
⑧ 품목별 연출컷(섹션 헤더 "| 워터리 블루" 식) — 음식 올린 식탁 사진 1~2장씩
⑨ 포장비 고지: "선물 포장 비용 3,000원 포함… 변심 교환·반품 시 배송비와 별도로 포장비 청구"
⑩ 체크리스트: 전자레인지 ☑가능 / 식기세척기 ☑가능 / 오븐 ☑불가 / 포장여부 ☑선물박스
⑪ 상품정보제공고시: 상품명·재질·사이즈("상세페이지 참조")·구성·원산지(일본)
⑫ 주의사항 11줄(사이즈 편차·모니터 색차·급격한 온도변화·거친 수세미·스크래치·붓질 편차·유약 흐름·완벽한 대칭 아님…)
⑬ "불량이 아닌 예시 이미지" 10컷 격자 + "제조 공정 특성상 자연 발생, 불량 사유 아님. 무료 교환·반품 불가"
```

**⑨~⑬은 상점 공통(모든 상품에 같은 이미지)**, ①~⑧만 상품별. 우리 "고정 문안 / 가변 칸" 분리와 같은 발상이다.

## 4. 소로이샵에서 **가져오지 않는 것**

| 소로이샵 | 왜 안 가져오나 |
|---|---|
| 품목마다 수식어 1개씩("사랑스러운·고급스러운·은은한·고풍스러운") | brand-voice §2: 형용사 대신 숫자·판단. 우리 자리는 "왜 들였는지" 한 줄 |
| 텍스트 전부 이미지 안 | 이미지 상세 자체는 흔하고 큰 불이익은 없다. 스마트스토어 검색은 상품명·태그·카테고리·주요정보·리뷰가 좌우하고 본문 텍스트 비중은 작다. 다만 이미지만 있으면 손님이 사이즈·케어를 복사·확대하기 어렵고, 문구 하나 고칠 때마다 이미지를 다시 만들어야 한다. **구성품 표·케어·주의 세 블록만 에디터 텍스트로 병기** |
| 주의사항 11줄 나열 | 다 읽히지 않는다. 우리는 3줄(안 어울리는 상황·개체차·파손) + '불량 아닌 예시' 사진이 대신 말한다 |
| 히어로 = 박스 연 컷 | 우리는 **한 상 차린 컷**(세트의 조합이 주장이라서). 박스 연 컷은 블록 6에 |
| 원산지 "일본"·"파스텔 블루" | 수입처 구조·팔레트가 다르다. 참고 대상 아님 |

## 5. 톤 메모

- 소로이샵: 해요체·합니다체 혼용, 느낌표 0, 이모지 0, 수식어 중간. 고지 문장은 사무적("청구됩니다", "고려하여 주십시오").
- 요소갤러리: 합니다체, 감성 수식 많음("단아한·여백의 미·일상에 스며듭니다"), 작가 1인칭 노트.
- 여기담기(목련상점 작성): 해요체 짧은 문장, `: )` 이모티콘, 기호(○ ▼)로 구조화. **개체차를 사진으로 보여주는 방식**은 좋다.
- 이나피스퀘어: 텍스트 3문장. 사진과 손그림 도안이 전부 말함. **우리 인스타 톤**에 가깝고 상세페이지 톤은 아니다.

우리 상세는 "구체적인"이 지배한다. 셋 중 어느 톤도 그대로 쓰지 않는다.
