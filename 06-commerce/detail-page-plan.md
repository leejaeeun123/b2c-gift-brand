## 0. 구조 한눈에

상세페이지 = **고정 블록 + 가변 칸 + 사진 슬롯** 세 층으로 나눈다. Figma 템플릿은 이 세 층을 그대로 레이어로 가진다.

| 층 | 뜻 | 누가 손대나 |
|---|---|---|
| **고정 문안** | 모든 상품에 똑같이 들어가는 글(포장·엽서·배송·표시사항 틀) | 한 번 확정하면 안 건드린다. 바뀌면 템플릿에서 한 번에 고친다 |
| **가변 칸** `{ }` | 상품마다 다른 글(세트명·조합의 이유·구성품 수치·케어 ○✕·단점) | 상품 1개당 **입력 시트 1장**(§3)을 채운다 |
| **사진 슬롯** `[ ]` | 블록마다 정해진 컷 수·비율 | 촬영 샷리스트(§4)대로 찍어 끼운다 |

블록 10개의 순서는 고정이다(`commerce.md` §04). 세트는 10개 전부, 단품은 1·3·4·5·8·9 여섯 개만 쓴다.

```
1 상황 라벨 + 세트명 → 2 조합의 이유 → 3 구성품 → 4 세척·가열 → 5 먼저 말씀드릴 것
→ 6 포장 → 7 받는 분께 → 8 배송·교환 → 9 표시 사항 → 10 낱개로 사기
```

## 1. 블록별 설계 — 무엇이 고정이고 무엇이 바뀌나

| # | 블록 | 고정 문안 | 가변 칸 | 사진 슬롯 | 그림 허용 |
|---|---|---|---|---|---|
| 1 | 상황 라벨 + 세트명 | 라벨 5종 중 택1(문구 고정) | `{세트명}` `{받는 상황 한 문장}` | 대표컷 1 (1:1 또는 4:5) | ○ 손글씨 제목 |
| 2 | 조합의 이유 | 없음 | `{왜 이 구성인가}` 한 단락 · `{무엇을 뺐는지와 이유}` 한 문장 | 구성품 나열컷 0~1 | ✕ |
| 3 | 구성품 | 표 머리글 (이름·사이즈·비교·재질·원산지) | 품목마다 `{이름}` `{수량}` `{지름/높이/길이}` `{용량}` `{비교 대상}` `{재질·원산지}` `{왜 들였는지}` | 품목별 단독컷 n | ✕ |
| 4 | 세척 · 가열 | 제목 `Use & Care` · 항목 4종 이름 · 아이콘 | `{○/✕}` ×4 · `{예외 품목 주의 한 줄}` | 없음 (아이콘) | ○ 손글씨 제목 1회 |
| 5 | 먼저 말씀드릴 것 | "도자기라 떨어뜨리면 깨집니다. 이중 박스와 완충재로 보냅니다." + **'불량이 아닌 예시' 사진 격자**(공용) | `{안 어울리는 상황}` `{개체차·색 차이}` | 개체차 클로즈업 1 + 공용 격자 6~9컷 | ✕ |
| 6 | 포장 | **설명 글 없음. 사진이 말한다.** 쇼핑백 옵션 2줄만 고정 (§2-6) | 없음 | 공정 3컷 + 열었을 때 1컷(엽서·네임택이 보이게) + 쇼핑백·스티커 1컷 | ○ 모티프 |
| 7 | 받는 분께 | **블록 6에 흡수.** 별도 글 없음 — 엽서가 꾸러미 위에 놓인 사진으로만 | 없음 | (6의 '열었을 때' 컷에 포함) | — |
| 8 | 배송 · 교환 | 전문 고정 (§2-8), 숫자만 확정 후 기입 | 없음 | 없음 | ✕ |
| 9 | 표시 사항 | 7항목 틀 고정 | `{구성품별 재질/원산지}` `{제조사·수입원}` `{주소}` | 없음 | ✕ |
| 10 | 낱개로 사기 | "구성품은 낱개로도 있습니다." | `{단품 링크 목록}` | 단품 썸네일 2~4 | ✕ |

**규칙 (commerce.md §04 그대로)**
- 가변 칸이 비면 그 블록은 올리지 않는다. 숫자·요일·금액은 확정값만.
- 그림(손글씨·거북이·모티프)은 1·6에만. 3·5·8·9는 글자와 사진뿐. 사진 위 합성 금지.
- **포장(6)·받는 분께(7)는 글로 설명하지 않는다**(재은 2026-11-07). 공정·엽서 동봉은 사진으로, 글은 쇼핑백 옵션 2줄뿐.
- 손글씨 문구 `Use & Care`는 블록 4 제목으로 한 페이지에 한 번.
- 긍정형으로 쓴다. "안 들였다"가 아니라 "…만 골랐습니다".

## 2. 고정 문안 — 확정본

모든 상품 상세에 그대로 들어가는 글이다. 여기서 한 번 정하고, 상품 시트에서는 다시 쓰지 않는다.

### 2-1. 상황 라벨 (블록 1, 택1)

```
집들이 · 이사  |  결혼 · 신혼  |  감사  |  생일  |  나에게
```

### 2-4. 세척 · 가열 (블록 4)

```
Use & Care                                  ← 손글씨 SVG text-use-and-care.svg

전자레인지 {○/✕} · 식기세척기 {○/✕} · 오븐 {○/✕} · 직화 {○/✕}
{예외 품목이 있으면: "수저는 전자레인지에 넣지 마세요." 식으로 품목명 명시}
```

네 항목 전부 쓴다. 아이콘은 `care-{microwave,dishwasher,oven,no-fire-oven}.svg` 계열, 항상 텍스트와 병행.

### 2-5. 먼저 말씀드릴 것 (블록 5) — 고정 1줄 + 가변 2줄

```
먼저 말씀드릴 것

{안 어울리는 상황 — 예: 자취방 1인용으로는 큽니다. 둘 이상 쓰실 때 권해 드려요.}
{개체차 — 예: 유약 특성상 개체마다 색이 조금씩 다릅니다. 사진과 미세한 차이는 불량이 아닙니다.}
도자기라 떨어뜨리면 깨집니다. 이중 박스와 완충재로 보냅니다.

[불량이 아닌 예시]  유약 뭉침 · 철점 · 핀홀 · 굽 거친 면 · 색 편차 … 6~9컷 격자
아래 사진의 특징은 만드는 과정에서 생기는 것이라 불량이 아닙니다. 이 이유로는 교환·반품이 어렵습니다.
```

도자기가 아닌 구성(유리 컵 등)이면 마지막 줄의 재질명만 바꾼다.
'불량이 아닌 예시' 격자는 소로이샵·요소갤러리·여기담기가 공통으로 쓰는 장치(`reference-detail-pages.md` §3). **한 번 찍어 전 상품 공용**, 글 11줄 대신 사진이 말한다.

### 2-6. 포장 (블록 6) — 사진 + 쇼핑백 안내 2줄

포장 과정·기본 포함·엽서 동봉은 **글로 설명하지 않는다.** 공정 3컷과 열었을 때 1컷(꾸러미 위에 엽서·네임택이 놓인 모습)이 그 자리를 대신한다. 글은 쇼핑백 옵션 안내만 둔다.

```
[사진] 에어캡 → 습자지 → 마끈   [사진] 열었을 때 — 꾸러미 위 엽서·네임택

쇼핑백은 선물용 추가 구성입니다 (+3,000원).
쇼핑백을 선택하시면 스티커가 함께 들어갑니다. 쇼핑백에 붙여 쓰시면 됩니다.

[사진] 쇼핑백 + 스티커
```

마끈은 박스 안, 리본은 쇼핑백 옵션에서만. 두 단어를 섞어 쓰지 않는다.

### 2-7. 받는 분께 (블록 7) — 블록 6에 흡수

엽서 문안 인용도, "엽서가 함께 갑니다"도 쓰지 않는다. 열었을 때 사진에 엽서가 보이면 충분하다. 엽서 전문은 받는 분이 처음 읽게 둔다.

### 2-8. 배송 · 교환 (블록 8) — 숫자는 확정 후 기입

```
배송 · 교환

{평일 오후 N시} 이전 주문은 당일 출고합니다. 주말·공휴일 주문은 다음 평일에 나갑니다.
택배 상자 안에 선물 상자가 한 번 더 들어가는 2겹 포장입니다.
파손된 채 도착하면 사진과 함께 알려 주세요. 같은 물건으로 다시 보냅니다.
교환·반품은 구입처(오하리상점)로 문의해 주세요. {반품 기준 — 수령 후 N일, 미사용}

단순 변심으로 돌려보내실 때는 받으신 그대로, 깨지지 않게 다시 싸서 보내 주세요.
돌아오는 길에 깨진 물건은 환불해 드리기 어렵고, 물건값을 청구하게 됩니다.
```

거북이 없음. 늦으면 늦는다고 날짜를 적는다.
변심 반품 2줄은 재은 결정(2026-11-07) — **포장 그대로 다시 싸서 보낼 것, 반송 중 파손은 환불 불가 + 제품값 배상.** 문장은 솔직하되 위협처럼 읽히지 않게, 이유(깨지기 쉬운 물건)를 앞에 둔다.

### 2-9. 표시 사항 (블록 9) — 작게, 구성품별

```
표시 사항

{품목} — 재질 {도자기} / 원산지 {대한민국} / 제조사(수입원) {상호} · {주소}
{품목} — 재질 {스테인리스 스틸} / 원산지 {대한민국} / 제조사(수입원) {상호} · {주소}
반품 및 교환: 구입처(오하리상점)
식품용                                       ← 식약처 공식 도안 mark-food-contact.svg, 변형 금지
```

### 2-10. 낱개로 사기 (블록 10)

```
낱개로 사기

구성품은 낱개로도 있습니다. 세트로 사시는 쪽이 낱개를 합친 값보다 저렴합니다.
{밥공기} · {접시} · {수저}   → 단품 페이지
```

가격 비교 채널에는 이 블록을 내보내지 않는다.
제조사·수입원은 **품목마다 다르다**(재은 2026-11-07) → 블록 9는 품목 행마다 상호·주소를 적는다. 입력 시트 블록 3의 품목 행에 같이 받는다.

### 2-11. 단품 전용 페이지 — 품목당 1장

세트 구성품은 **하나씩 따로 페이지를 만든다.** 그 물건 하나만 설명하고, 짧게.

```
[1] 상황 라벨 없음 · {품목명}            ← 세트 상세 블록 1의 단품 판
[3] {품목명} ×1  {지름/높이 · 용량}  {비교 대상}  {재질 · 원산지}
    → {왜 들였는지 한 줄}                 ← 이 한 줄이 '조합의 이유'를 대신한다
[4] Use & Care  전자레인지 {○/✕} · 식기세척기 {○/✕} · 오븐 {○/✕} · 직화 {○/✕}
[5] 먼저 말씀드릴 것  {개체차} · 깨집니다 · [불량 아닌 예시 공용 격자]
[8] 배송 · 교환 (공통)
[9] 표시 사항 (그 품목 1행)
    "이 물건이 들어간 세트 → {세트명}"     ← 세트로 되돌리는 링크 한 줄
```

- 사진은 세트 때 찍은 **단독컷(C) 1~2장 재사용.** 새로 찍지 않는다.
- 블록 2(조합)·6(포장)·10(낱개)은 없다. 포장은 세트와 같으니 공정 사진 1컷만 넣어도 된다.
- 단품 페이지끼리 서로 링크하지 않는다. 돌아가는 길은 세트뿐 — 단품이 주인공이 되는 자리를 만들지 않는다.

## 3. 상품 입력 시트 — 상품 1개당 이 한 장

상품을 추가할 때 **이 표만** 채운다. 칸 이름은 Figma 텍스트 레이어 이름과 1:1로 맞춘다(§5).

```
  무게 라벨        : (가벼운 / 기본 / 조금 특별한)      ← 진열용, 상세에는 안 보임

  받는 상황 한 문장 :
  가격             :

■ 블록 2 — 조합의 이유
  왜 이 구성인가 (한 단락, 2~3문장) :
  무엇을 뺐는지와 이유 (한 문장)     :

  품목 n  이름 :            수량 :
```

### 3-2. 채운 예시 — 둘이 쓰는 첫 상 (commerce.md 예문, 가상 구성)

```
■ 기본
  상황 라벨        : 집들이 · 이사
  무게 라벨        : 기본
  세트명           : 둘이 쓰는 첫 상
  받는 상황 한 문장 : 신혼집에 빈손으로 가기 어려우실 때.
  가격             : {확정 후}

■ 블록 2
  왜 이 구성인가    : 신혼집에는 그릇이 이미 있습니다. 그래서 겹칠 확률이 가장 낮은 것들로 골랐습니다.
  무엇을 뺐는지     : 큰 접시는 뺐습니다 — 집들이 선물로 가장 많이 겹치는 물건이라서요.
```

## 4. 촬영 샷리스트 — 사진 슬롯

사진이 나오는 날 이 표대로 찍으면 템플릿 슬롯이 그대로 채워진다. 전 컷 공통: **자연광 · 흰 배경 · 파스텔 필터·비네팅 금지**, 소품은 린넨·나무만.

| 슬롯 | 블록 | 컷 수 | 구도·비율 | 비고 |
|---|---|---|---|---|
| A 대표컷 | 1 | 1 | 한 상 차린 세트 전체, 위에서 45°, 1:1 또는 4:5 | 썸네일 첫 장과 겸용 |
| B 나열컷 | 2 | 0~1 | 구성품을 한 줄로 늘어놓은 톱뷰 | 생략 가능 |
| C 단독컷 | 3 | 품목 수만큼 | 흰 배경 정면 또는 45°, 1:1 | **손 또는 밥공기를 같이 찍어** 실제 크기가 보이게 (P3 대응) |
| D 클로즈업 | 5 | 1 | 유약·개체차가 보이는 거리 | 두 점을 나란히 두고 색 차이를 솔직하게 |
| D2 불량 아닌 예시 | 5 | 6~9 | 1:1 접사, 유약 뭉침·철점·핀홀·굽 거친 면·색 편차 | **전 상품 공용.** 들여온 물건 중 실제 사례로 한 번만 |
| E 포장 공정 | 6 | 3 | 에어캡 감싸는 손 → 습자지 → 마끈 묶기 | 세로 또는 1:1, 손이 들어간다 |
| F 열었을 때 | 6 | 1 | 박스 뚜껑 연 직후, 꾸러미 위에 **엽서·네임택이 놓인** 모습 | 이 한 컷이 "엽서가 함께 갑니다"를 대신한다. 인스타 겸용 |
| G 쇼핑백·스티커 | 6 | 1 | 쇼핑백 옆에 스티커, 또는 스티커 붙인 쇼핑백 | 옵션 안내 2줄 옆에 |
| H 단품 썸네일 | 10 | 2~4 | C와 동일 컷 재사용 | 새로 안 찍어도 됨 |

- D2·E·F·G는 **한 번 찍어 모든 상품에 돌려쓴다.** 상품마다 새로 찍는 건 A·C·D(+B)뿐.
- 세로로 긴 한 벌로 합칠 때 가로 860px, 블록 사이 여백 80px.

## 5. Figma 템플릿 설계 메모 (사진 나온 뒤 착수)

지금 정해 두면 나중에 레이어 이름만 보고 채울 수 있는 것들.

| 항목 | 정함 |
|---|---|
| 프레임 | `detail-set` (10블록) · `detail-single` (6블록). 가로 860, 블록당 섹션 컴포넌트, 상하 80 |
| 컴포넌트 | 블록 1개 = 컴포넌트 1개 (`blk-01-hero` … `blk-10-single`). 블록 3의 품목 행은 반복 컴포넌트 `row-item` |
| 텍스트 레이어 이름 | 입력 시트 칸 이름 그대로: `set-name` `set-situation` `why-combo` `what-removed` `item-name` `item-size` `item-compare` `item-material` `item-reason` `care-microwave` … `exception-note` `caveat-fit` `caveat-variance` (블록 6·7은 텍스트 레이어 없음, 쇼핑백 2줄은 고정) |
| 사진 레이어 이름 | 슬롯 문자 그대로: `photo-A` `photo-B` `photo-C-1…n` `photo-D` `photo-E-1~3` `photo-F` `photo-G` `photo-H-1…n` |
| 고정 문안 | §2의 글은 컴포넌트 안에 **잠금**. 상품 인스턴스에서 오버라이드하지 않는다 |
| 케어 아이콘 | `care-*` 7종을 variant(가능/불가)로 묶어 ○/✕ 토글 |
| 색·서체 | 토큰만: `--paper` `--ink` `--line` `--muted`, Pretendard 300/400, 손글씨는 SVG |
| 내보내기 | 블록별 PNG 또는 세로 한 장 → 스마트스토어 상세 업로드 |
| 텍스트 병기 | 상세 본문은 이미지로 올려도 된다. 다만 **구성품 표·케어·주의(3·4·5)는 에디터 텍스트로도 한 번 더** 넣는다 — 이유는 검색보다 복사·확대·수정 편의. 검색 노출은 상품명·태그·카테고리·'상품 주요정보'가 좌우한다 (`reference-detail-pages.md` §4) |

이렇게 하면 상품 추가 = **인스턴스 복제 → 시트 칸 붙여넣기 → 사진 교체**로 끝난다.

## 6. 확정해야 템플릿이 닫히는 값

고정 문안 중 아직 비어 있는 숫자·상호. 이것들이 채워지기 전엔 블록 6·8·9를 올리지 않는다.

- [ ] 출고 마감 시각 (블록 8 "평일 오후 N시") — 아직 모름 (재은 11-07)
- [ ] 반품 기준 일수·조건 (블록 8) — 논의 예정. 변심 반품 규칙(다시 싸서 보낼 것·반송 중 파손은 환불 불가+물건값 청구)은 확정, 일수만 남음
- [ ] 변심 반품 시 포장비(쇼핑백 3,000원 등) 차감 여부 — 소로이샵은 고지함. 반품 기준과 같이 결정
- ⚠️ 반품 기준 정할 때 확인: 전자상거래법상 단순 변심 청약철회는 수령 후 7일 안에 가능하고, 반송 중 파손 책임은 보낸 쪽에 있다. "환불 불가" 문구는 **파손된 경우에 한해** 쓰고, 멀쩡히 돌아온 변심 반품을 막는 문장으로 읽히면 안 된다
- [ ] 제조사/수입원 상호·주소 (블록 9) — **품목마다** 사입처 확정 시
- [x] 단품 전용 페이지 형태 — **품목당 1장, 간단하게** (§2-11). `curation-criteria.md` §6-4의 미결 하나 닫힘
- [ ] 실제 1호 세트 구성 — 지금 예시는 전부 가상 구성
