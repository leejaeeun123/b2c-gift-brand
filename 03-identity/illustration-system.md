## 1. 정본은 "그린 것"이지 "생성한 것"이 아니다

**모티프 정본 = 재은이 만든 레퍼런스 시트를 그대로 벡터화한 것.**
코드로 형태를 만들지 않는다. 그림이 먼저 있고, 코드는 그걸 **따기만** 한다.

```
그림(PNG)  →  vectorize.py  →  motif-*.svg / char-*.svg
```

- `vectorize.py`가 하는 일: 이진화 → 조각 묶기(가까운 점·눈은 한 모티프로) → 행 순서 정렬 → 윤곽선 추출 → `fill-rule="evenodd"` 단일 패스
- **형태는 1픽셀도 바꾸지 않는다.** 손이 그은 선의 압력·망설임·비대칭이 그대로 남는다
- 재현: `python vectorize.py [png경로]`

### 코드로 그리려다 실패한 기록

처음에 형태를 코드로 생성했다(`_deprecated/gen_motifs.py`). 규칙은 지켜졌지만 결과가 틀렸다.

| 시도 | 결과 |
|---|---|
| 얇은 선 + 잔떨림 | 손그림이 아니라 **깔끔한 벡터 아이콘** |
| 진폭을 키움 | 선이 자글거려 **노이즈** |
| 굵은 마커선으로 전환 | 톤은 가까워졌으나 **형태가 어색**(화병이 전구로, 접시가 눈알로) |

**교훈**: 손그림에서 코드가 만들 수 있는 건 떨림이지 **형태 감각**이 아니다. "왜 이 선이 여기 있는지"는 손이 정한다. 코드의 자리는 그 뒤, 따고 관리하는 일이다.

## 2. 스타일 (레퍼런스에서 읽은 것)

새 모티프를 추가할 때 지켜야 할 성격이다.

| # | 특징 |
|---|---|
| 1 | **얇고 고른 선.** 붓펜이 아니라 가는 펜. 두께 변화가 거의 없다 |
| 2 | **모서리가 둥글다.** 각진 곳이 없고 전체가 부풀어 있다 |
| 3 | **삐뚤삐뚤하다.** 원이 정확한 원이 아니고, 좌우가 다르다 |
| 4 | **작은 얼굴을 넣기도 한다.** 점 눈 + 작은 입. 잔·화병·거북이·강아지에 있다 |
| 5 | **디테일은 무늬로.** 물결(볼 테두리), 점(거북이 등·배), 빗금(물고기 지느러미) |
| 6 | **면을 칠하지 않는다.** 하트만 예외적으로 굵게 |

### 새 모티프가 필요할 때

1. 같은 도구로 **시트를 한 장 더 만든다** (기존 시트를 참조 이미지로 넣어 스타일을 고정)
2. `python vectorize.py 새시트.png` 로 벡터화
3. `NAMES` 배열에 순서대로 이름을 넣는다 (좌→우, 위→아래)

**낱개로 만들지 말고 시트로 만든다.** 한 장에 같이 그려야 선의 성격이 유지된다.

### 지금 없는 것 (다음 시트에서)
편지 · 선물 상자 · 트레이 · 주전자 · 냄비 — 상황 라벨 아이콘도 여기서 나온다.

## 3. 파일 사양

```
viewBox 0 0 100 100 · fill="currentColor" · fill-rule="evenodd" · stroke="none"
```

- **선이 아니라 면이다.** 윤곽을 따서 채운 형태라 `stroke-width`로 굵기를 바꿀 수 없다.
- 색은 부모의 `color`만 바꾸면 된다. 잉크/종이 양방향으로 쓴다.
- 크기를 키워도 깨지지 않지만, **아주 작게 쓰면 얇은 선이 사라진다.** 24px 이하에서는 별도 축소용이 필요하다(미제작).

---

## 4. 어디에 쓰나 / 어디에 안 쓰나

| ✅ 쓴다 | ❌ 안 쓴다 |
|---|---|
| 띠지 · 박스 · 스티커 · 완충지 | **제품 사진 위** |
| 메시지 카드 · 감사 카드 | 로고 대체 (로고는 워드마크) |
| 상황 라벨 아이콘 (진열·필터) | 배경 전면 패턴 (여백을 먹는다) |
| 상세페이지 구분선 · 스펙 아이콘 | 상품 썸네일 (상품이 안 보인다) |
| 인스타 단독 그래픽 · 에디토리얼 | 3개 이상 겹쳐 쌓기 |

**배치**: 한 화면에 **최대 2개**. 여백이 곧 가격대다(비주얼 원칙 3).

## 5. 남은 일

- **24px 이하 축소용 세트.** 얇은 선이라 파비콘·작은 아이콘에서 사라진다. 선을 굵힌 별도 버전이 필요하다.
- **없는 모티프 5종**(편지·선물 상자·트레이·주전자·냄비) 추가 시트.
- **상황 라벨 5종 전용 아이콘**(집들이·이사 / 결혼·신혼 / 감사 / 생일 / 나에게).
