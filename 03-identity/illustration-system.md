# 일러스트 시스템

> **이 문서가 브랜드의 차별점 그 자체다.** 상품은 도매라 남과 겹치지만, 이 그림은 겹치지 않는다.
> 목표는 그림 한 장이 아니라 **누가 그려도 같은 손으로 보이게 하는 규칙**이다.

---

## 1. 선의 규칙 (7개)

> **레퍼런스: 이나피스퀘어(INAP)** — 굵은 마커펜, 일부러 어긋난 비례, 아이가 그린 듯한 단순화.
> 여기에 "삐뚤삐뚤한 선"이 포인트다.

| # | 규칙 | 왜 |
|---|---|---|
| 1 | **굵은 마커선.** 기준 두께 6.2 (viewBox 100 기준) | 가는 선은 벡터 아이콘으로 읽힌다. **굵기가 손그림의 첫 조건이다** |
| 2 | **끝은 둥글게** (round cap/join) | 뾰족한 끝은 기계로 읽힌다 |
| 3 | **닫힌 도형은 닫는다** | 굵은 선에서 벌어진 틈은 '손맛'이 아니라 **파손**으로 보인다 |
| 4 | **좌우를 대칭으로 맞추지 않는다** | 완전 대칭은 즉시 기계로 읽힌다 |
| 5 | **크고 느린 흔들림.** 진폭 0.95 / 주파수 0.028 | 삐뚤삐뚤함은 "많이"가 아니라 **"크고 느리게"**. 잔떨림은 노이즈가 된다 |
| 6 | **디테일을 뺀다.** 한 모티프에 요소 4개 이하 | 굵은 선에서는 내부 디테일이 서로 붙어 뭉갠다. 못 그린 게 아니라 **안 그린 것**이어야 한다 |
| 7 | **면을 통으로 채워도 된다** | INAP의 개미·곰처럼 강조용 실루엣 허용. 단 한 화면에 하나까지 |

### 실패 기록 (되돌아가지 않기 위해)

| 시도 | 결과 |
|---|---|
| 얇은 선(2.6) + 잔떨림(진폭 0.34, 주파수 0.045) | 손그림이 아니라 **깔끔한 벡터 아이콘**. 레퍼런스와 방향이 달랐다 |
| 진폭 0.55 / 주파수 0.16 | 선이 자글거려 **노이즈**로 읽혔다 |
| 닫힌 도형을 3~5% 열어 두기 | 얇은 선에선 손맛이었지만 굵은 선에선 **깨진 그릇**처럼 보였다 |
| 화병 + 꽃 (요소 5개) | 목이 뭉개져 **전구·막대사탕**으로 읽혔다 → 꽃 한 송이로 단순화 |
| 위에서 본 등껍질 | 동심원은 구명튜브, 육각+방사선은 거미줄 → 폐기 |

## 2. 모티프 사전 v1 — 14종

| | | |
|---|---|---|
| `motif-plate` 접시 | `motif-bowl` 볼 | `motif-mug` 머그 |
| `motif-glass` 잔 | `motif-teapot` 주전자 | `motif-spoon` 수저 |
| `motif-cutlery` 포크와 나이프 | `motif-tray` 트레이 | `motif-flower` 꽃 |
| `motif-candle` 초 | `motif-ribbon` 리본 매듭 | `motif-letter` 편지 |
| `motif-box` 선물 상자 | `motif-pear` 배 | |

- 사양: `viewBox 0 0 100 100`, `stroke="currentColor"`, 기본 획 **6.2**, 기본 잉크 `#262320`
- **`currentColor`이므로 부모의 `color`만 바꾸면 잉크·종이 양방향으로 쓴다.** 파일을 색깔별로 복제하지 않는다.
- 팔레트가 2색이라 **모티프가 화면의 유일한 그래픽 요소**다. 그만큼 선의 완성도가 중요해졌다.
- 시안: [`motifs-preview.html`](./motifs-preview.html) · 재현: `python gen_motifs.py`

### 구성 원칙
- **식기 8종 + 선물 4종 + 계절/정물 2종.** 식기가 절반을 넘어야 테이블웨어 브랜드로 읽힌다.
- 확장은 카테고리가 아니라 **상황 라벨**을 따라간다. 예: 집들이 → 냄비·수세미, 결혼 → 촛대·꽃다발.
- 사람·얼굴은 그리지 않는다. 다만 **캐릭터 거북이 1종은 예외**로 채택했다 → [`character.md`](./character.md). 거북이 외의 캐릭터는 만들지 않는다.

## 3. 어디에 쓰나 / 어디에 안 쓰나

| ✅ 쓴다 | ❌ 안 쓴다 |
|---|---|
| 띠지 · 박스 · 스티커 · 완충지 | **제품 사진 위** |
| 메시지 카드 · 감사 카드 | 로고 대체 (로고는 워드마크) |
| 상황 라벨 아이콘 (진열·필터) | 배경 전면 패턴 (여백을 먹는다) |
| 상세페이지 구분선 · 스펙 아이콘 | 상품 썸네일 (상품이 안 보인다) |
| 인스타 단독 그래픽 · 에디토리얼 | 3개 이상 겹쳐 쌓기 |

**배치**: 한 화면에 **최대 2개**. 여백이 곧 가격대다(비주얼 원칙 3).

## 4. 정직하게 — 이 v1의 한계

이 14종은 **코드로 생성한 시안**이다. 규칙을 고정하고 방향을 눈으로 확인하려고 만들었다.

- 장점: 규칙이 문서와 코드에 동시에 박혀 있어 **누가 이어받아도 같은 손**이 나온다. 색·크기 변경이 즉시 반영된다.
- 한계: 진짜 손이 그은 선의 **압력 변화와 망설임**은 없다. 자세히 보면 균질하다.

> **권장 경로**: 이 14종을 밑그림으로 삼아 태블릿이나 종이에 **다시 그린 뒤 벡터로 따는 것.** 그때도 §1의 7개 규칙은 그대로 적용한다. 규칙이 먼저 있고 손이 나중에 오는 순서라, 다시 그려도 시스템은 무너지지 않는다.
>
> 다시 그리지 않고 이대로 가도 쓸 수는 있다. 다만 그 경우 **"AI가 그린 귀여움"으로 읽힐 위험**을 완전히 지우지는 못한다 — 그게 이 브랜드에서 가장 피해야 할 결과다.
