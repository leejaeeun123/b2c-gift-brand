# 로고 방향 — 오하리상점 / OHARI

> 네이밍 확정(2026-08-30) · 착수 조건(KIPRIS 21류 조회) 통과. 시안: [`lockup-options.html`](./lockup-options.html) (`python build_lockup.py`)

## 확정

1. **워드마크 단독.** 심볼을 따로 만들지 않는다.
   - 이유: 우리는 이미 **모티프 14종**이라는 그래픽 자산을 갖는다. 여기에 심볼까지 얹으면 그림이 둘이 되어 서로를 깎는다. 타입라운지에서도 심볼(솔리드 팬)을 폐기하고 워드마크 단독으로 간 전례가 있다.
   - 예외: 후보 `포개`·`나란히`가 선택되면 이름 자체가 도형(겹침/나란함)이라 **워드마크 안에 도형이 내장**되는 형태가 가능하다. 그때도 분리된 심볼은 만들지 않는다.

2. **손그림 워드마크.** 폰트를 쓰지 않고 직접 그린다.
   - `illustration-system.md` §1의 선 규칙 6개를 그대로 적용한다. 로고와 모티프가 같은 손이어야 한다.

3. **정본이 둘이다 — 한글과 영문을 한 락업에 묶지 않는다.** *(2026-09-01 개정)*

   | | 정본 | 쓰는 자리 |
   |---|---|---|
   | 한글 | **오하리상점** — 한 줄 단독 | 스마트스토어·톡스토어 대문, 자사몰 헤더, 상세페이지, 인스타 프로필 |
   | 영문 | **OHARI** — 자간 넓힌 단독 | 박스, 띠지, 봉인 스티커, 쇼핑백 |

   - 이전 결정(*"한글이 주 표기이고 영문은 락업 하단에 작게"*)은 **폐기.** 하나의 락업이 두 언어를 지면
     스토어 대문에서는 영문이 군더더기가 되고, 박스에서는 한글이 면을 시끄럽게 한다. 자리가 다르면 로고도 다르다.
   - 근거는 그대로다 — 국내 검색 유입이 매출 축이라 **웹은 한글**. 패키지는 검색 대상이 아니고
     상품(그릇) 사진이 색을 지므로 **면이 조용해야 한다 → 영문**.
   - **'오하리' 단독 대외 노출 금지**는 유지. 한글 정본이 `오하리상점`이므로 규칙과 충돌하지 않는다.
   - 정사각 자리(박스 도장·프로필)는 한글 **세로 2줄 변형**을 쓴다. 아래 줄을 자간으로 늘려 폭을 맞춘다.
   - 거북이는 워드마크에 상시로 붙이지 않는다. 띠지·카드에서 **단독으로만** 나온다(§1 심볼 금지).

4. **최종 산출은 벡터 아웃라인.** 폰트·이미지 의존 0.
   - 한글 가로 / 한글 세로 2줄 / 영문 × 잉크·화이트 = 6종 + `currentColor` 3종.
   - 진행 순서: **HTML 시안으로 배치·비례 확정 → 손그림 시트 → `vectorize.py` → SVG.**
     형태를 코드가 만들지 않는 규칙(`illustration-system.md` §1)이 로고에도 적용된다.

## 남은 결정

*(2026-09-01 전부 확정)*

- [x] **영문 자간 `.22`** — 좁게(.06)는 덩어리져 손맛이 남고 넓게(.42)는 작게 줄이면 흩어진다. 중간값 채택
- [x] **한글 세로 2줄 변형 제외** — 정본은 가로 한 줄 하나. 정사각 자리는 축약형(거북이)이 맡는다
- [x] **축약형은 거북이 단독** — `오`·`O` 폐기. 파비콘·봉인 스티커·도자기 각인 전부 거북이

> 축약형을 글자가 아니라 거북이로 정하면서 **작은 자리에서는 세계관이 먼저 보인다.**
> 심볼 금지 조항(§1)과 충돌하지 않는다 — 거북이는 워드마크 옆에 상시로 붙지 않고, 워드마크가 못 들어가는 자리에서만 혼자 선다.
