# 타이포그래피

> **제목은 손그림이 맡는다.** 그래서 서체는 한 종이면 충분하고, 오히려 담백해야 한다.

## 본문 서체 — Wanted Sans

| | |
|---|---|
| 서체 | **Wanted Sans** (원티드랩, 오픈 라이선스 · 상업적 사용 가능) |
| 웨이트 | **400 Regular / 700 Bold** 2웨이트만 |
| 폴백 | `Pretendard, -apple-system, system-ui, sans-serif` |

### 왜
- 또렷하고 담백해 손그림이 시끄럽지 않게 받쳐 준다.
- **숫자 가독성이 좋다.** 커머스에서 가격·사이즈·용량이 계속 나오는데, 이게 실제로 중요하다.
- Pretendard는 국내에 너무 흔해 브랜드 인상이 생기지 않는다. Paperlogy는 타입라운지가 쓰고 있어 겹친다.

## 스케일

| 역할 | 크기 | 웨이트 | 자간 |
|---|---|---|---|
| 페이지 제목 | 28 / 32 | 700 | -1% |
| 섹션 제목 | 20 | 700 | -1% |
| 소제목 | 16 | 700 | 0 |
| 본문 | 15 | 400 | 0 |
| 캡션·스펙 | 13 | 400 | 0 |
| 라벨(상황 태그) | 12 | 700 | +2% |

- 행간: 본문 **1.7**, 제목 1.35. 여백이 가격대라는 원칙이 행간에도 적용된다.
- 한글 자간은 0을 기본으로. 제목만 -1%.
- **숫자는 절대 축약하지 않는다** — `5만원` ✕ / `50,000원` ○. 보이스 '구체적인'의 타이포 판이다.

## 금지
- 3웨이트 이상 사용 (300 Light·900 Black 금지 — 얇으면 약해 보이고 굵으면 소리친다)
- 서체 2종 혼용. 제목용 디스플레이 서체를 따로 두지 않는다 — **그 자리가 손그림 자리다**
- 캘리그라피·손글씨 폰트 (회피 방향)
- 이탤릭 (한글에 없다)
- 전체 대문자 영문 강조 (소리치는 인상)
