# 타이포그래피

> **제목은 손그림이 맡는다.** 그래서 서체는 한 종이면 충분하고, 오히려 담백해야 한다.

## 본문 서체 — Pretendard

| | |
|---|---|
| 서체 | **Pretendard** (SIL OFL · 상업적 사용 자유 · 웹/데스크톱 모두) |
| 웨이트 | **400 Regular / 700 Bold** 2웨이트만 |
| 스택 | `"Pretendard", "Apple SD Gothic Neo", "Malgun Gothic", system-ui, sans-serif` |

### 왜 — 흔한 것이 장점이다 (2026-08-30 변경)

처음에는 Wanted Sans를 골랐고, 이유가 *"Pretendard는 국내에 너무 흔해 브랜드 인상이 생기지 않는다"*였다.
**이 논리가 이 문서의 첫 줄과 어긋난다.** 브랜드 인상을 만드는 자리는 손그림이라고 해 놓고,
배경 역할인 본문 서체에 인상을 요구했다.

본문 서체는 눈에 띄지 않는 것이 임무다. 그리고 커머스에서는 **흔한 것이 실무 이점**이다.

| | 이유 |
|---|---|
| **어디서나 깨지지 않는다** | 자사몰·스마트스토어 에디터, 협업자 PC, 상세페이지 외주, 인쇄소 — 설치돼 있거나 즉시 받을 수 있다 |
| **숫자·영문이 안정적** | 가격·지름·용량이 계속 나온다. 폭이 고르고 1과 l이 구분된다 |
| **웨이트가 넉넉하다** | 9단계 중 400·700만 골라 쓴다. 나중에 필요해져도 서체를 갈아탈 일이 없다 |
| **라이선스가 자유롭다** | SIL OFL. 인쇄물·굿즈·이미지 굽기 전부 가능 |

> Wanted Sans도 무료이고 숫자가 좋다. 바꿔야만 하는 문제는 아니었고, **바꾸는 편이 이득인 문제**였다.
> 흔하다는 유일한 단점은 본문에서는 단점이 아니다.

### ⚠️ 브랜드가 서는 자리는 따로 있다

서체를 흔한 것으로 내리는 대신, 구별은 **손그림 워드마크 · 모티프 · 거북이**가 전부 진다.
이 셋이 약하면 서체를 아무리 골라도 브랜드가 서지 않는다.

## 스케일

| 역할 | 크기 | 웨이트 | 자간 |
|---|---|---|---|
| 페이지 제목 | 28 / 32 | 700 | -1% |
| 섹션 제목 | 20 | 700 | -1% |
| 소제목 | 16 | 700 | 0 |
| 본문 | 15 | 400 | 0 |
| 캡션·스펙 | 13 | 400 | 0 |
| 라벨(상황 태그) | 12 | 700 | +2% |

- 행간: 본문 **1.7**, 제목 1.35. 여백이 가격대라는 원칙이 행간에도 적용된다.
- 한글 자간은 0을 기본으로. 제목만 -1%.
- **숫자는 절대 축약하지 않는다** — `5만원` ✕ / `50,000원` ○. 보이스 '구체적인'의 타이포 판이다.

## 금지
- 3웨이트 이상 사용 (300 Light·900 Black 금지 — 얇으면 약해 보이고 굵으면 소리친다)
- 서체 2종 혼용. 제목용 디스플레이 서체를 따로 두지 않는다 — **그 자리가 손그림 자리다**
- 캘리그라피·손글씨 폰트 (회피 방향)
- 이탤릭 (한글에 없다)
- 전체 대문자 영문 강조 (소리치는 인상)
