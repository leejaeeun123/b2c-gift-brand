# 캐릭터 — 거북이

> **먼저 정정한다.** `visual-principles.md`에 "마스코트 캐릭터를 얼굴로 세우기"를 회피 방향으로 적어 놓고,
> 차별점은 "캐릭터·세계관으로 확장하는 자체 그림 자산"이라고 썼다. 앞뒤가 맞지 않았다.
>
> 정리하면 이렇다. **캐릭터가 로고를 대신하고 상품을 이기는 것**이 위험한 것이지, 세계 안에 반복 등장하는
> 캐릭터 자체가 위험한 게 아니다. 오히려 그림 자산을 IP로 키우는 3단계 확장 경로에서는 **캐릭터가 있어야
> 굿즈로 넘어간다.** 회피 항목을 조건부로 수정하고, 거북이를 채택한다.

---

## 왜 거북이인가

| 의미 | 브랜드와의 연결 |
|---|---|
| **행운·장수의 상징** | 선물에 얹어 보내는 마음. "복 받으세요"를 말이 아니라 그림으로 |
| **등에 지고 간다** | 우리가 하는 일 그 자체 — 물건을 지고 받는 분께 간다 |
| **오래 곁에 둔다** | 그릇은 오래 쓰는 물건이다. 유행을 타는 캐릭터와 반대편에 있다 |
| **천천히 간다** | 급하게 팔지 않고 골라서 보낸다는 태도 |

한국·동아시아에서 거북이는 설명 없이 읽히는 상징이라 **카피가 필요 없다.** 띠지에 거북이 하나만 있어도 뜻이 전달된다.

### ⚠️ 리스크 하나 — 느림

거북이는 **"배송이 느리다"**로 읽힐 수 있다. 커머스에서 이건 실제 손해다.

**대응 규칙**: 배송·발송·물류 맥락에는 거북이를 쓰지 않는다.
송장·배송 안내·발송 지연 공지에 거북이가 등장하면 안 된다. 거북이가 사는 자리는 **띠지·카드·스티커·에디토리얼**이다.

## 형태 3종

| 파일 | 이름 | 쓰는 자리 |
|---|---|---|
| `char-turtle.svg` | **거북이** | 주 형태. 카드·에디토리얼·안내 |
| `char-turtle-gift.svg` | **선물을 진 거북이** | 띠지·박스·발송 완료 알림 |
| `char-turtle-shell.svg` | **등껍질** | 파비콘·스티커·작은 자리 (24px 이하) |

- `viewBox 0 0 100 100`, `currentColor`, 선 규칙은 모티프와 동일(`illustration-system.md` §1)
- 등껍질을 위에서 본 형태는 **동심원으로 그리지 않는다** — 구명튜브로 읽힌다. 육각 갑판 + 방사선이 정본이다

## 규칙

| ✅ | ❌ |
|---|---|
| 띠지·카드·스티커·완충지 | **로고 자리** (로고는 워드마크 단독) |
| 에디토리얼 삽화 | 상품 사진 위 |
| 파비콘(등껍질) | 배송·물류 맥락 |
| 안내 문구 옆 작게 | 옷 입히기·소품 들리기 |
| 한 화면에 **하나** | 표정 여러 개 만들기 |

### 표정과 변형
- **눈은 점 하나.** 입·눈썹·볼터치를 그리지 않는다. 감정을 주는 순간 캐릭터가 상품보다 커진다.
- 포즈 변형은 **최대 5종까지**. 그 이상은 캐릭터 사업이지 편집숍이 아니다.
- 이름을 붙이지 않는다. 이름이 생기면 손님이 캐릭터를 사러 온다.

> 원칙 하나로 요약하면 — **거북이는 주인공이 아니라 배달하는 사람이다.** 화면의 주인공은 언제나 그릇이다.

## 확장 경로 (PLAN §3.1과 연결)

| 단계 | 거북이가 있는 곳 |
|---|---|
| 1 지금 | 띠지·카드·스티커·완충지 |
| 2 소량 PB | **머그·접시에 거북이 전사** ← 여기서 캐릭터가 상품이 된다 |
| 3 IP 확장 | 엽서·행주·테이블매트·자석 |

2단계가 이 캐릭터의 존재 이유다. 거북이 없이 PB를 하면 "도매 그릇에 우리 이름만 박은 것"이 되고,
거북이가 있으면 **그 그릇은 우리만 만들 수 있다.**
