# 네이밍 기준

> 이름은 **손그림 워드마크로 그려질 것**이고, **한글 검색으로 유입될 것**이다. 이 둘이 다른 기준을 요구한다.

---

## 필수 조건 (하나라도 어긋나면 탈락)

| # | 조건 | 이유 |
|---|---|---|
| 1 | **한글 2~4음절.** 1음절 금지 | 1음절은 검색·상표 식별력이 모두 약하다 |
| 2 | 듣고 바로 쓸 수 있을 것 | 검색 유입이 매출의 축이다. 받아쓰기가 안 되면 못 찾아온다 |
| 3 | **획이 적어 손으로 그릴 수 있을 것** | 워드마크가 손그림이다. 받침이 겹치고 획이 많으면 작은 사이즈에서 뭉갠다 |
| 4 | 카테고리에 갇히지 않을 것 | '그릇·도자기·세라믹·테이블'을 이름에 넣으면 3단계 확장(굿즈·PB)이 막힌다 |
| 5 | 상표·도메인·인스타 핸들 중 **2개 이상 확보 가능** | 하나도 못 잡으면 브랜드가 아니라 별명이다 |
| 6 | 유아적이지 않을 것 | 파스텔 함정의 언어판. 3~7만 원이 설명되지 않는다 |

## 가점

- **주는 행위**가 이름에 들어 있을 것 (A축이 이름에서부터 보인다)
- 한 단어로 끝날 것 — 짧을수록 손그림이 산다
- 조어이거나 어간형이어서 **상표 식별력이 높을 것** (일반명사는 등록도 검색도 불리하다)
- 영문 병기가 어색하지 않을 것 (해외 도매·입점 대비)

## 금지

| 금지 | 이유 |
|---|---|
| `~그릇` `~도자기` `세라믹` `테이블` | 조건 4 위반 |
| `~서울` 붙이기 | 로파서울 따라하기로 읽힌다 |
| `소소한` `온기` `일상의` 류 감성 형용사 | 캘리그라피 클리셰. 보이스(구체적·솔직한)와 충돌 |
| `기프트` `gift` 직접 노출 | 검색 경쟁이 지옥이고 상표 식별력이 없다 |
| 일반명사 단독 (`보자기`, `선물`) | 상표 등록 난이도 + 검색 결과가 상품에 먹힌다 |
| 영문 단독 조어 | 한글 검색 유입을 포기하는 선택. 로고는 한글 손그림이 컨셉에 맞다 |

## 재생성 규칙

전 후보 탈락 시 **기준 1축만 완화**해 재생성한다. 최대 3라운드, 이후 사용자와 재협의.
완화 우선순위: 조건 5 → 조건 1 → 가점 항목. **조건 3·4는 완화하지 않는다** (로고와 확장성을 직접 깎는다).
