> 오하리상점 판매 화면 규칙 — 네이버 스마트스토어 [smartstore.naver.com/dando_nmwc](https://smartstore.naver.com/dando_nmwc) 를 먼저 연다. 자사몰은 없다.
> 확정본 (2026-11-01). 세트와 단품을 둘 다 팔되 **진열의 1차 축은 상황**, 단품은 종속 진열. 이 탭은 컴포넌트가 아니라 **진열·상세 규칙** 위주다.

## 01. Principles

| 원칙 | 내용 |
|---|---|
| **상황이 먼저 보인다** | 진열·배너·썸네일에서 가장 먼저 읽혀야 하는 건 상품명도 브랜드명도 아니라 **상황 라벨** |
| **색 없이 위계** | 포인트 컬러가 없다. 강조는 면 반전(잉크 채움)과 크기·여백으로. 상품 사진이 화면의 유일한 채도 |
| **세트가 주장, 단품은 밸브** | 세트는 상품이자 주장. 단품은 재고 밸브·보충·시험 구매 자리 — 주인공이 되는 자리를 만들지 않는다 |
| **구체적인이 지배** | 상세페이지는 보이스 3속성 중 **구체적인**이 지배한다. 사이즈·세척 가부 없는 상세는 미완성 |
| **대문·헤더는 영문 로고** | 스마트스토어 대문·프로필은 `OHARI STORE` 워드마크. 상호 텍스트는 '오하리상점' |

## 02. Tokens

웹·상세페이지·인쇄가 모두 여기서 값을 가져간다. **하드코딩 금지** — 색·크기·간격은 토큰 이름으로만.

```css
:root{
  /* color — 2색이 전부, 포인트 컬러 없음 */
  --paper:#FFFFFF;  --ink:#262320;
  --line:rgba(38,35,32,.14);   /* 경계선 = 잉크 투명도 */
  --muted:rgba(38,35,32,.55);  /* 보조 텍스트 */
  --faint:rgba(38,35,32,.06);  /* 면 구분 */

  /* type — 본문 Light/Regular, 제목은 손글씨 SVG */
  --font:"Pretendard","Apple SD Gothic Neo","Malgun Gothic",system-ui,sans-serif;
  --w-light:300; --w-regular:400;
  --fs-title:22px; --fs-sub:16px; --fs-body:15px; --fs-caption:13px; --fs-label:12px;
  --lh-body:1.7; --lh-title:1.35;

  /* space — 4px 배수 */
  --s1:4px; --s2:8px; --s3:12px; --s4:16px; --s5:24px; --s6:32px; --s7:48px; --s8:64px;

  /* shape */
  --r-sm:6px; --r-md:10px; --r-lg:16px;
  --stroke:2.6;   /* 모티프 기본 획 (viewBox 100 기준) */
}
```

### 최소 컴포넌트 (스마트스토어 상세·배너용)

| 요소 | 표현 |
|---|---|
| 기본 버튼 · 선택된 상황 라벨 | 잉크 채움 + 종이 글씨 |
| 보조 버튼 · 미선택 라벨 | `--line` 테두리 + 잉크 글씨 |
| 카드 (상품·세트) | 종이 배경 + `--line` 1px 테두리 — 흰 상품 사진과 페이지 배경의 경계는 **테두리**가 만든다 |
| 가격 | Pretendard 400, 숫자는 항상 400. 할인 전 가격은 `--muted` + 취소선 |
| 품절 · 비활성 | `--muted` + 테두리, "품절" 텍스트 명시 |
| 경고 · 마감 | 텍스트로 ("오늘 발송 마감") — 빨간색 없음 |

```tl-pills
집들이 · 이사* | 결혼 · 신혼 | 감사 | 생일 | 나에게
```

## 03. 진열

**1차 = 상황 / 2차 = 무게 / 필터 = 카테고리.** 상품 타입(접시·볼·잔)은 카테고리가 아니라 **필터**다 — 타입으로 진열하는 순간 요소갤러리·쿠도와 구조가 같아진다.

### 상황 라벨 (1차)
| 순서 | 라벨 | 페르소나 | 예산 중심 | 비고 |
|---|---|---|---|---|
| 1 | **집들이 · 이사** | P1 | 4~6만 | **주력.** 진열 첫 번째 |
| 2 | **결혼 · 신혼** | P1 | 5~7만 | 2인 세트가 자연스럽게 붙는다 |
| 3 | **감사** | P2 | 2~4만 | 엽서·카드가 결정적 |
| 4 | **생일** | P2 | 3~5만 | 사시사철 |
| 5 | **나에게** | P3 | 3~7만 | 재구매의 축. 진열 순서는 뒤 |

제외: 취업·입학 · 명절 · 돌/출산. 시즌 컬러 총동원 없음 — 상황 카테고리는 사시사철 도는 게 강점.

### 무게 (2차)
| 라벨 | 가격대 | 성격 |
|---|---|---|
| 가벼운 | ~30,000 | 단품 + 카드. 부담 안 주는 자리 |
| **기본** | 30,000~50,000 | **주력 구간.** 2인 세트 완결 |
| 조금 특별한 | 50,000~70,000 | 세트 + 한 점 추가 |

### 필터 (카테고리 아님)
접시 · 볼 · 컵/잔 · 머그 · 수저·커트러리 · 서빙/트레이 · 소품(수저받침·코스터) · 카드·포장

### 세트와 단품
| | 세트 | 단품 |
|---|---|---|
| 자리 | **1차 진열.** 상황 라벨 안 | **종속 진열.** 세트 상세 하단 "낱개로 사기" + 전용 페이지 1장 |
| 역할 | 상품이자 주장 | 재고 밸브 · 보충 · 시험 구매 |
| 문장 | 조합의 이유 | 기준 문장(왜 들였는지)만 |
| 가격 비교 채널 | 올린다 | **올리지 않는다** |

가드레일 4개 — ① 단품가 합 = 세트가 + 10~15% (세트가 항상 이득) ② 포장 손이 상품가를 넘는 소품은 2점 이상 묶음 ③ **단품 전용 사입 금지** (낱개는 이미 세트에 있는 품목만) ④ 단품도 같은 포장(에어캡·습자지·마끈). 포장 등급을 낮추지 않는다.

### 판매 구조 (소로이샵에서 채용)
- **개수 세트(2P·3P) 규격화** — 입문 가격대(2~3만) 라인
- **한정수량** 카테고리 — 재입고 불확실을 판매 장치로
- **재입고 알림** — 재방문을 만든다
- 1차 카테고리(상황)는 **우리 것을 지킨다.** 가격 포지션은 따라가지 않는다(소로이 3,500~27,500원 vs 우리 3~7만)

## 04. 상품 상세

**순서는 고정.** 빠지면 미완성 상세페이지다.

```tl-seq
상황 라벨 + 세트명 > 조합의 이유 (왜 이 구성인가) > 한 상 차린 사진 > 구성품 표 (사이즈 · 비교 대상) > 세척 · 가열 (케어 아이콘 + 텍스트) > 단점을 먼저 (안 어울리는 상황) > 포장 공정 사진 > 법정 표기 · 배송 > 낱개로 사기
```

| 블록 | 규칙 | 예 |
|---|---|---|
| 세트명 | 상황이 읽히는 이름. 거북이·브랜드명을 넣지 않는다 | 둘이 쓰는 첫 상 |
| 조합의 이유 | 한 단락. **무엇을 뺐는지**까지 | "큰 접시는 뺐습니다 — 집들이 선물로 가장 많이 겹치는 물건이라서요." |
| 기준 문장 | 상품마다 한 줄, 예외 없이. 형용사 대신 **판단** | "국물 있는 반찬을 올려도 옆 그릇에 안 닿는 깊이라 들였습니다." |
| 구성품 표 | 지름/높이/용량 mm·ml + **비교 대상** + 재질 + 원산지 | "지름 21cm. 파스타 2인분이 담깁니다. 밥공기보다 조금 큽니다." |
| 세척 · 가열 | 전자레인지 · 식기세척기 · 오븐 · 직화 **네 항목 전부**, 아이콘 + 텍스트 | 전자레인지 ○ · 식기세척기 ○ · 오븐 ✕ · 직화 ✕ |
| 단점 먼저 | 안 맞는 상황 · 개체차 · 파손 | "유약 특성상 개체마다 색이 조금씩 다릅니다." |
| 포장 | 공정 사진 (에어캡 → 습자지 → 마끈) + "기본 포장 포함" 명시 | 쇼핑백은 옵션으로 |
| 배송 · 법정 | 출고일 · 2겹 포장 · 반품 기준 · 라벨 7항목 | **거북이 없음** |

- **확실하지 않은 수치는 아예 쓰지 않는다.** 도매처에서 세척 정보가 확인 안 되면 그 상품은 들이지 않는다.

### 상세페이지 템플릿 (스마트스토어)

세로로 긴 이미지 한 벌 + 텍스트 블록. **가로 860px**(스마트스토어 PC·모바일 공용 권장폭), 블록마다 위아래 여백 80px, 배경 흰색, 글씨는 Pretendard 300/400. 손글씨·거북이는 블록 제목 자리에만. 아래 10블록을 순서대로 채우면 한 페이지가 된다.

| # | 블록 | 이미지 | 텍스트 (채워 넣는 자리) |
|---|---|---|---|
| 1 | **상황 라벨 + 세트명** | 한 상 차린 대표 사진 1장 (1:1 또는 4:5) | `[집들이 · 이사]` 라벨 → `{세트명}` → 한 줄 `{받는 상황을 한 문장으로}` |
| 2 | **조합의 이유** | 없음 (텍스트만) 또는 구성품 나열 사진 | `{왜 이 구성인가}` 한 단락 + `{무엇을 뺐는지와 이유}` 한 문장 |
| 3 | **구성품** | 품목별 단독 컷 (흰 배경) | 품목마다: `{이름}` · `{지름/높이 mm · 용량 ml}` · `{비교 대상: "밥공기보다 조금 큽니다"}` · `{재질 · 원산지}` · `{왜 들였는지 한 줄}` |
| 4 | **세척 · 가열** | 케어 아이콘 4종 (`USE & CARE` 손글씨 제목) | `전자레인지 {○/✕} · 식기세척기 {○/✕} · 오븐 {○/✕} · 직화 {○/✕}` + 예외 품목이 있으면 품목명 명시 |
| 5 | **먼저 말씀드릴 것** | 개체차·유약 클로즈업 | `{안 어울리는 상황}` · `{개체차·색 차이}` · "도자기라 떨어뜨리면 깨집니다" |
| 6 | **포장** | 포장 공정 3컷 (에어캡 → 습자지 → 마끈) + 열었을 때 1컷 | "기본 포장이 포함되어 있습니다" + 포장 순서 한 줄 + `쇼핑백은 옵션(+{금액})` |
| 7 | **받는 분께** | 엽서·네임택 사진 | 엽서 뒷면 문안 첫 줄 인용 + "세트마다 엽서·네임택이 함께 갑니다" |
| 8 | **배송 · 교환** | 없음 | `{출고 요일/시간}` · "2겹 포장(택배 상자 + 선물 상자)" · `{파손 시 처리}` · `{교환·반품 기준}` — 거북이 없음 |
| 9 | **표시 사항** | 없음 (작게) | 라벨 7항목: 재질 / 수입원 / 제조사 / 주소 / 원산지 / 반품·교환 / 식품용 — 구성품별 |
| 10 | **낱개로 사기** | 단품 썸네일 2~4개 | "구성품은 낱개로도 있습니다" + 단품 링크 (가격 비교 채널엔 미노출) |

```
[1] 집들이 · 이사
    둘이 쓰는 첫 상
    신혼집에 빈손으로 가기 어려우실 때.

[2] 신혼집에는 그릇이 이미 있습니다. 그래서 겹칠 확률이 가장 낮은 것들로 골랐습니다.
    큰 접시는 뺐습니다 — 집들이 선물로 가장 많이 겹치는 물건이라서요.

[3] 밥공기 ×2  지름 11cm · 높이 6cm · 350ml  손에 쥐었을 때 가볍습니다.  도자기 · 대한민국
    접시 ×2    지름 21cm  파스타 2인분이 담깁니다. 밥공기보다 조금 큽니다.  도자기 · 대한민국
    수저 1벌   길이 22cm  스테인리스 스틸 · 대한민국
    → 국물 있는 반찬을 올려도 옆 그릇에 안 닿는 깊이라 들였습니다.

[4] USE & CARE   전자레인지 ○ · 식기세척기 ○ · 오븐 ✕ · 직화 ✕
    (수저는 전자레인지에 넣지 마세요.)

[5] 먼저 말씀드릴 것
    유약 특성상 개체마다 색이 조금씩 다릅니다. 사진과 미세한 차이는 불량이 아닙니다.
    자취방 1인용으로는 큽니다. 둘 이상 쓰실 때 권해 드려요.
    도자기라 떨어뜨리면 깨집니다. 이중 박스와 완충재로 보냅니다.

[6] 포장   한 점씩 에어캡 → 습자지 → 검정 마끈으로 묶어, 같은 높이로 담습니다.
    기본 포장이 포함되어 있습니다. 쇼핑백은 옵션입니다.

[7] 받는 분께   "우리는 천천히 오래가는 것들을 좋아합니다." — 엽서와 네임택이 함께 갑니다.

[8] 배송   평일 오후 2시 이전 주문 당일 출고. 택배 상자 + 선물 상자 2겹.
    파손 시 사진과 함께 알려 주시면 같은 물건으로 다시 보냅니다. 교환·반품은 구입처(오하리상점).

[9] 표시 사항   밥공기·접시 — 도자기 / 대한민국 · 수저 — 스테인리스 스틸 / 대한민국 · 식품용
    제조사·주소 {확정 후 기입}

[10] 낱개로 사기   밥공기 · 접시 · 수저  → 단품 페이지
```

- 숫자·요일·금액은 **확정값만**. `{ }` 자리가 비면 그 블록은 올리지 않는다.
- 블록 1·6·7에만 그림(손글씨·거북이·모티프)이 들어간다. 3·5·8·9는 글자와 사진뿐.
- 단품 상세는 같은 틀에서 **1·3·4·5·8·9**만 쓴다. 2(조합의 이유)와 10은 빠지고, 3의 "왜 들였는지" 한 줄이 2를 대신한다.

- 긍정형으로 쓴다 — "안 들였다"가 아니라 "…만 골랐습니다".
- 손글씨 문구(`A Little Care` · `Use & Care`)는 세척 블록 제목으로만, 한 페이지에 한 번.

## 05. 썸네일

| 규칙 | 내용 |
|---|---|
| 정사각 1:1 | 흰 배경(`--paper`) · 그릇 사진 위에 아무것도 얹지 않는다 |
| 첫 장 | **한 상 차린 세트 전체**. 단품 클로즈업은 2장째부터 |
| 상황 라벨 | 사진 밖, 하단 좌측 텍스트 `label` 400 — 로고보다 먼저 읽힌다 |
| 로고 | 썸네일에 넣지 않는다 (대문에 있다) |
| 그림 | 모티프·거북이는 **여백 썸네일**(세트 소개 배너)에만, 상품 썸네일에는 없음 |
| 시즌 | 에디션(크리스마스 끈 색)만 사진으로 표시, 배지·스티커 금지 |
