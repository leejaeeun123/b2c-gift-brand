# b2c-gift-brand

테이블웨어(식기·도자기) 중심 **온라인 선물 편집숍**의 브랜드 시스템.
전략·큐레이션 기준·네이밍·손그림 아이덴티티·패키징·커머스 적용을 md 정본으로 관리한다.

## 현재 상태 (2026-08-23)

**Phase 0·1 완료 · Phase 2 네이밍 보류 · Phase 3 아이덴티티 진행 중(로고 제외).**

| | |
|---|---|
| 컨셉 | 선물가게 · 테이블웨어 온라인 편집숍 |
| 단계 | 사업 검토 → 거래처 발굴 → 런칭 |
| 비주얼 | 낙서/손그림 (로고 포함) |
| 큐레이션 축 | 🟢 **A. 주는 마음(관계)** — 진열 1차 축은 상황, 카테고리는 필터 |
| 차별점 | 🟢 **자체 그림 자산** — 포장·카드 → 소량 PB → 자체 라인 3단계 ([`PLAN.md` §3.1](./PLAN.md)) |
| 공방 | ⏸ 지금은 없음. 3단계에서 **우리 그림 × 특징 있는 공방**으로 재합류 |
| 소싱 | 도매 기반으로 빠르게 오픈 (공방 없음) |
| 가격대 | 🟢 세트 **3~5만 원**, 상단 **7만 원대** — 캐주얼 선물 |
| 주 레퍼런스 | 🟢 **로파서울** 구성 참조 ([해부](./01-strategy/reference-lofa.md)) · 단 가격 포지션은 다름 |
| 진열 축 | 🟢 1차 **상황**(집들이·이사 / 결혼·신혼 / 감사 / 생일 / 나에게) · 2차 **무게**(가벼운/기본/조금 특별한) · 카테고리는 필터 |
| 보이스 | 🟢 **다정한데 호들갑스럽지 않은 · 구체적인 · 솔직한** |
| 무드 | 🟢 **손의 흔적 · 담백한 밝음 · 넉넉한 여백** (회피: 파스텔·AI티·핸드메이드 클리셰·갤러리 무채색) |
| 컬러 | 🟢 **2색** — 종이 `#FFFFFF` · 잉크 `#262320`. 포인트 컬러 없음, 전 인쇄물 1도 |
| 서체 | 🟢 **Wanted Sans** 400/700 2웨이트 (제목 자리는 손그림이 맡는다) |
| 일러스트 | 🟢 **모티프 16종** — 레퍼런스 시트를 벡터화한 정본. 코드로 그리지 않는다 ([시안](./03-identity/motifs-preview.html)) |
| 캐릭터 | 🟢 **거북이** — 행운을 등에 지고 간다. 로고 자리엔 안 세운다 ([규칙](./03-identity/character.md)) |
| 로고 | ⏸ 워드마크 단독·손그림으로 방향만 확정. 네이밍 대기 |
| 네이밍 | 🟡 40안 → 결선 4안 **건네 · 겸상 · 포개 · 나란히** (전부 검색 충돌 없음). 방향 선택 대기 |
